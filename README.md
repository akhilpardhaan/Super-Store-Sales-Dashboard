# Super-Store-Sales-Analysis-Dashboard

# Overview

An interactive **Power BI dashboard** developed to analyze Super Store sales, profit, orders, customer segments, product categories, regions, and shipping performance. The project also includes a **15-day sales forecast**.

# Tools Used

**Power BI**
**Power Query**
**DAX**
**Data Visualization**
**Sales Forecasting**

# Key Analysis

* Sales, Orders, Profit & Ship Days
* Category & Sub-Category Performance
* Regional & State-wise Sales
* Customer Segment & Payment Mode Analysis
* Monthly Sales & Profit Trends
* Ship Mode Analysis
**15-Day Sales Forecast**

# Key Insights

 **Total Sales:** 1.57M
 **Total Orders:** 22K
 **Total Profit:** 175.26K
 **Average Ship Days:** 4
 **Top Category:** Office Supplies
 **Top Region:** West

# Objective

To transform sales data into **interactive business insights** and support **data-driven decision-making** through Power BI.
